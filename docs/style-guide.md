# Brideline Style Guide

## Design Foundations

| Element | Specification | Use |
| --- | --- | --- |
| Primary color | #D2647D | Primary actions, selected states and active elements |
| Accent colors | #EDBEC6, #EDBEC8 | Backgrounds, accents and soft visual emphasis |
| Warning | #F7EFE0 | Pending states and warnings |
| Error | #F8E2E7 | Error messages and unsuccessful actions |
| Success | #EAF3EC | Successful outcomes and confirmations |

## Typography

| Role | Font | Size |
| --- | --- | --- |
| Screen title | Archivo SemiBold | 22 sp |
| Section heading | Archivo SemiBold | 18 sp |
| Body text | Archivo Regular | 16 sp |
